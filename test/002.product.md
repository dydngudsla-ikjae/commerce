# 002.product — 테스트 시나리오

## 카테고리 생성 (POST /api/v1/admin/categories)

- [x] 카테고리 생성 API가 유효한 이름으로 카테고리를 등록한다
- [x] 카테고리 생성 API가 parent_id로 하위 카테고리를 생성한다
- [x] 카테고리 생성 API가 존재하지 않는 parent_id를 404 CATEGORY_NOT_FOUND로 거부한다
- [x] 카테고리 생성 API가 ADMIN 권한 없이 403을 반환한다

## 카테고리 목록 조회 (GET /api/v1/categories)

- [x] 카테고리 목록 API가 부모-자식 계층 트리 구조로 반환한다
- [x] 카테고리 목록 API가 카테고리가 없으면 빈 배열을 반환한다

## 상품 생성 (POST /api/v1/admin/products)

- [x] 상품 생성 API가 유효한 정보로 상품을 등록한다
- [x] 상품 생성 API가 존재하지 않는 category_id를 404 CATEGORY_NOT_FOUND로 거부한다
- [x] 상품 생성 API가 ADMIN 권한 없이 403을 반환한다

## 상품 목록 조회 (GET /api/v1/products)

- [x] 상품 목록 API가 ON_SALE 상품을 반환한다
- [x] 상품 목록 API가 STOPPED 상품을 제외한다
- [x] 상품 목록 API가 deleted 상품을 제외한다
- [x] 상품 목록 API가 모든 Variant가 SOLD_OUT인 상품도 목록에 포함한다
- [x] 상품 목록 API가 created_at DESC 순으로 반환한다
- [x] 상품 목록 API가 category_id로 필터링한다
- [x] 상품 목록 API가 page/size로 페이지네이션한다

## 상품 상세 조회 (GET /api/v1/products/{id})

- [x] 상품 상세 API가 Product, Options, Variants를 포함해 반환한다
- [x] 상품 상세 API가 존재하지 않는 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 상품 상세 API가 deleted 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 상품 상세 API가 STOPPED 상품에 404 PRODUCT_NOT_FOUND를 반환한다

## 상품 수정 (PUT /api/v1/admin/products/{id})

- [x] 상품 수정 API가 name, description, status, category_id를 수정한다
- [x] 상품 수정 API가 존재하지 않는 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 상품 수정 API가 deleted 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 상품 수정 API가 ADMIN 권한 없이 403을 반환한다
- [ ] 상품 수정 API가 STOPPED 상품을 정상적으로 수정한다

## 상품 삭제 (DELETE /api/v1/admin/products/{id})

- [x] 상품 삭제 API가 논리 삭제(deleted=true)로 처리한다
- [x] 상품 삭제 API가 존재하지 않는 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 상품 삭제 API가 이미 삭제된 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 상품 삭제 API가 ADMIN 권한 없이 403을 반환한다

## 옵션 추가 (POST /api/v1/admin/products/{id}/options)

- [x] 옵션 추가 API가 상품에 옵션명과 값을 추가한다
- [x] 옵션 추가 API가 동일 상품 내 옵션명 중복 시 409 OPTION_DUPLICATE를 반환한다
- [x] 옵션 추가 API가 존재하지 않는 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] 옵션 추가 API가 ADMIN 권한 없이 403을 반환한다

## Variant 생성 (POST /api/v1/admin/products/{id}/variants)

- [x] Variant 생성 API가 가격과 재고로 Variant를 생성한다
- [x] Variant 생성 API가 재고 0인 Variant를 SOLD_OUT 상태로 생성한다
- [ ] Variant 생성 API가 재고가 있는 Variant를 ON_SALE 상태로 생성한다
- [x] Variant 생성 API가 동일 옵션 조합 중복 시 409 DUPLICATE_VARIANT를 반환한다
- [x] Variant 생성 API가 존재하지 않는 상품에 404 PRODUCT_NOT_FOUND를 반환한다
- [x] Variant 생성 API가 ADMIN 권한 없이 403을 반환한다

## Variant 수정 (PUT /api/v1/admin/variants/{id})

- [x] Variant 수정 API가 price와 status를 수정한다
- [x] Variant 수정 API가 존재하지 않는 Variant에 404 VARIANT_NOT_FOUND를 반환한다
- [x] Variant 수정 API가 ADMIN 권한 없이 403을 반환한다

## 재고 수정 (PUT /api/v1/admin/variants/{id}/stock)

- [x] 재고 수정 API가 stock을 변경한다
- [x] 재고 수정 API가 stock을 0으로 변경 시 SOLD_OUT으로 자동 전환한다
- [x] 재고 수정 API가 stock을 양수로 복구 시 ON_SALE로 자동 전환한다
- [x] 재고 수정 API가 음수 재고 요청을 거부한다
- [x] 재고 수정 API가 존재하지 않는 Variant에 404 VARIANT_NOT_FOUND를 반환한다
- [x] 재고 수정 API가 ADMIN 권한 없이 403을 반환한다

- [ ] 동시 재고 차감 요청에서 재고 초과분은 실패하고 성공 건만 재고를 차감한다
