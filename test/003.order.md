### 주문 생성 API (`POST /api/v1/orders`)
- [x] 주문 생성 API가 단일 Variant 주문을 성공적으로 생성한다
- [x] 주문 생성 API가 다중 Variant 주문을 하나의 트랜잭션으로 생성한다
- [x] 주문 생성 API가 초기 상태를 PENDING으로 설정한다
- [x] 주문 생성 API가 total_amount를 Σ(price × quantity)로 계산한다
- [x] 주문 생성 API가 주문 시점의 price와 product_name을 OrderItem에 스냅샷으로 저장한다
- [x] 주문 생성 API가 재고를 차감한다
- [x] 주문 생성 API가 SOLD_OUT Variant 주문 요청을 거부한다 (400, VARIANT_SOLD_OUT)
- [x] 주문 생성 API가 STOPPED Variant 주문 요청을 거부한다 (400, VARIANT_SOLD_OUT)
- [x] 주문 생성 API가 존재하지 않는 Variant 요청을 거부한다 (404, VARIANT_NOT_FOUND)
- [x] 주문 생성 API가 재고 부족 시 주문 생성을 실패한다 (400, OUT_OF_STOCK)
- [x] 주문 생성 API가 재고 부족 아이템이 포함된 다중 주문 전체를 롤백한다
- [x] 주문 생성 API가 비인증 요청을 거부한다 (401)
- [x] 주문 생성 API가 quantity 0 요청을 거부한다 (400)
- [x] 주문 생성 API가 동일 Variant를 중복 포함한 주문을 각각 독립 차감으로 처리한다
- [x] 주문 생성 API가 상품 가격 변경 후에도 OrderItem의 price를 주문 시점 값으로 유지한다

### 결제 API (`POST /api/v1/orders/{id}/pay`)
- [x] 결제 API가 PENDING 주문을 PAID로 전이한다
- [x] 결제 API가 PAID 주문 재결제 요청을 거부한다 (400, ORDER_INVALID_STATUS)
- [x] 결제 API가 CANCELLED 주문 결제 요청을 거부한다 (400, ORDER_INVALID_STATUS)
- [x] 결제 API가 타인 주문 접근을 거부한다 (403, ORDER_ACCESS_DENIED)
- [x] 결제 API가 존재하지 않는 주문 요청을 거부한다 (404, ORDER_NOT_FOUND)
- [x] 결제 API가 비인증 요청을 거부한다 (401)

### 취소 API (`POST /api/v1/orders/{id}/cancel`)
- [x] 취소 API가 PENDING 주문을 CANCELLED로 전이한다
- [x] 취소 API가 주문 취소 시 OrderItem 수량만큼 재고를 복구한다
- [x] 취소 API가 재고 복구 시 SOLD_OUT 상태의 Variant를 ON_SALE로 전환한다
- [x] 취소 API가 PAID 주문 취소 요청을 거부한다 (400, ORDER_INVALID_STATUS)
- [x] 취소 API가 CANCELLED 주문 재취소 요청을 거부한다 (400, ORDER_INVALID_STATUS)
- [x] 취소 API가 타인 주문 접근을 거부한다 (403, ORDER_ACCESS_DENIED)
- [x] 취소 API가 존재하지 않는 주문 요청을 거부한다 (404, ORDER_NOT_FOUND)
- [x] 취소 API가 비인증 요청을 거부한다 (401)

### 주문 목록 조회 API (`GET /api/v1/orders`)
- [x] 주문 목록 조회 API가 본인 주문만 반환한다
- [x] 주문 목록 조회 API가 다른 사용자의 주문을 결과에 포함하지 않는다
- [x] 주문 목록 조회 API가 created_at DESC 정렬을 적용한다
- [x] 주문 목록 조회 API가 page/size 기반 pagination을 적용한다
- [x] 주문 목록 조회 API가 비인증 요청을 거부한다 (401)

### 주문 상세 조회 API (`GET /api/v1/orders/{id}`)
- [x] 주문 상세 조회 API가 Order와 OrderItem 목록을 반환한다
- [x] 주문 상세 조회 API가 타인 주문 접근을 거부한다 (403, ORDER_ACCESS_DENIED)
- [x] 주문 상세 조회 API가 존재하지 않는 주문 요청을 거부한다 (404, ORDER_NOT_FOUND)
- [x] 주문 상세 조회 API가 비인증 요청을 거부한다 (401)
