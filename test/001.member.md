# 001.member — 테스트 시나리오

## 회원가입 (POST /api/v1/auth/signup)

- [x] 회원가입 API가 유효한 이메일과 비밀번호로 회원을 등록한다
- [x] 회원가입 API가 이메일을 소문자로 저장한다
- [x] 회원가입 API가 비밀번호를 bcrypt로 암호화해 저장한다
- [x] 회원가입 API가 기본 role을 CUSTOMER로 설정한다
- [x] 회원가입 API가 기본 status를 ACTIVE로 설정한다
- [x] 회원가입 API가 중복 이메일을 409 MEMBER_ALREADY_EXISTS로 거부한다
- [x] 회원가입 API가 8자 미만 비밀번호를 거부한다
- [x] 회원가입 API가 영문 대문자 없는 비밀번호를 거부한다
- [x] 회원가입 API가 영문 소문자 없는 비밀번호를 거부한다
- [x] 회원가입 API가 숫자 없는 비밀번호를 거부한다

## 로그인 (POST /api/v1/auth/login)

- [x] 로그인 API가 유효한 자격증명으로 인증에 성공한다
- [ ] 로그인 API가 성공 시 Access Token을 발급한다
- [ ] 로그인 API가 성공 시 Refresh Token을 발급하고 DB에 저장한다
- [ ] 로그인 API가 성공 시 login_fail_count를 0으로 초기화한다
- [ ] 로그인 API가 성공 시 last_login_at을 갱신한다
- [ ] 로그인 API가 존재하지 않는 이메일에 401 AUTH_INVALID를 반환한다
- [ ] 로그인 API가 비밀번호 불일치 시 401 AUTH_INVALID를 반환한다
- [ ] 로그인 API가 LOCKED 회원에 401 AUTH_INVALID를 반환한다
- [ ] 로그인 API가 INACTIVE 회원에 401 AUTH_INVALID를 반환한다
- [ ] 로그인 API가 인증 실패 시 login_fail_count를 원자적으로 증가시킨다
- [ ] 로그인 API가 5회 연속 실패 시 회원 상태를 LOCKED로 전환한다
- [ ] 로그인 API가 last_login_at 업데이트 실패 시에도 로그인을 성공 처리한다

## 토큰 재발급 (POST /api/v1/auth/refresh)

- [ ] 토큰 재발급 API가 유효한 Refresh Token으로 새 Access Token과 Refresh Token을 발급한다
- [ ] 토큰 재발급 API가 재발급 후 기존 Refresh Token을 삭제한다
- [ ] 토큰 재발급 API가 만료된 Refresh Token에 401 TOKEN_EXPIRED를 반환한다
- [ ] 토큰 재발급 API가 유효하지 않은 Refresh Token에 401 TOKEN_INVALID를 반환한다
- [ ] 토큰 재발급 API가 Access Token을 Refresh Token으로 사용하면 거부한다
- [ ] 토큰 재발급 API가 이미 사용된 Refresh Token 재사용 시 401 TOKEN_INVALID를 반환한다

## 로그아웃 (POST /api/v1/auth/logout)

- [ ] 로그아웃 API가 로그아웃 시 Refresh Token을 삭제한다
- [ ] 로그아웃 API가 인증 없이 요청 시 401을 반환한다

## 회원 탈퇴 (DELETE /api/v1/members/me)

- [ ] 회원 탈퇴 API가 회원 status를 DELETED로 변경한다
- [ ] 회원 탈퇴 API가 이메일에 _deleted_{timestamp} 접미사를 붙인다
- [ ] 회원 탈퇴 API가 name을 탈퇴 사용자로 변경한다
- [ ] 회원 탈퇴 API가 탈퇴 시 Refresh Token을 삭제한다
- [ ] 회원 탈퇴 API가 탈퇴 후 동일 이메일로 재가입을 허용한다
- [ ] 회원 탈퇴 API가 인증 없이 요청 시 401을 반환한다

## JWT 인증 필터

- [ ] 인증 필터가 유효한 Access Token으로 인증 컨텍스트를 설정한다
- [ ] 인증 필터가 만료된 Access Token으로 인증 컨텍스트를 비운다
- [ ] 인증 필터가 서명이 잘못된 Access Token으로 인증 컨텍스트를 비운다
- [ ] 인증 필터가 Refresh Token을 Access Token으로 사용하면 인증 컨텍스트를 비운다
- [ ] 인증 필터가 ADMIN 권한 없는 회원의 admin 엔드포인트 접근 시 403을 반환한다
