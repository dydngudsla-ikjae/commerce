# 001.member — 테스트 시나리오

## 회원가입 (POST /api/v1/auth/signup)

- [x] 회원가입 API가 유효한 이메일과 비밀번호로 회원을 등록한다
- [x] 회원가입 API가 이메일을 소문자로 저장한다
- [x] 회원가입 API가 비밀번호를 bcrypt로 암호화해 저장한다
- [x] 회원가입 API가 기본 role을 CUSTOMER로 설정한다
- [x] 회원가입 API가 기본 status를 ACTIVE로 설정한다
- [x] 회원가입 API가 중복 이메일을 409 MEMBER_ALREADY_EXISTS로 거부한다
- [x] 회원가입 API가 8자 미만 비밀번호를 거부한다
- [x] 회원가입 API가 영문 대문자 없는 비밀번호를 거부한다
- [x] 회원가입 API가 영문 소문자 없는 비밀번호를 거부한다
- [x] 회원가입 API가 숫자 없는 비밀번호를 거부한다

## 로그인 (POST /api/v1/auth/login)

- [x] 로그인 API가 유효한 자격증명으로 인증에 성공한다
- [x] 로그인 API가 성공 시 Access Token을 발급한다
- [x] 로그인 API가 성공 시 Refresh Token을 발급하고 DB에 저장한다
- [x] 로그인 API가 성공 시 login_fail_count를 0으로 초기화한다
- [x] 로그인 API가 성공 시 last_login_at을 갱신한다
- [x] 로그인 API가 존재하지 않는 이메일에 401 AUTH_INVALID를 반환한다
- [x] 로그인 API가 비밀번호 불일치 시 401 AUTH_INVALID를 반환한다
- [x] 로그인 API가 LOCKED 회원에 401 AUTH_INVALID를 반환한다
- [x] 로그인 API가 INACTIVE 회원에 401 AUTH_INVALID를 반환한다
- [x] 로그인 API가 5회 연속 실패 시 올바른 비밀번호로도 로그인을 차단한다
- [x] 로그인 2번 시 첫 번째 Refresh Token이 무효화된다
- [ ] 로그인 API가 대소문자 혼합 이메일(User@Example.COM)로도 소문자 변환 후 로그인에 성공한다
- [ ] 로그인 API가 4회 실패 후 성공 시 login_fail_count를 0으로 초기화한다
- [ ] 로그인 API가 DELETED 회원 로그인 시 401 AUTH_INVALID를 반환한다

## 토큰 재발급 (POST /api/v1/auth/refresh)

- [x] 토큰 재발급 API가 유효한 Refresh Token으로 새 Access Token과 Refresh Token을 발급한다
- [x] 토큰 재발급 API가 재발급 후 기존 Refresh Token을 삭제한다
- [x] 토큰 재발급 API가 만료된 Refresh Token에 401 TOKEN_EXPIRED를 반환한다
- [x] 토큰 재발급 API가 유효하지 않은 Refresh Token에 401 TOKEN_INVALID를 반환한다
- [x] 토큰 재발급 API가 Access Token을 Refresh Token으로 사용하면 거부한다
- [x] 토큰 재발급 API가 이미 사용된 Refresh Token 재사용 시 401 TOKEN_INVALID를 반환한다
- [x] 만료된 Access Token을 Refresh Token으로 재발급 받을 수 있다

## 로그아웃 (POST /api/v1/auth/logout)

- [x] 로그아웃 API가 로그아웃 시 Refresh Token을 삭제한다
- [x] 로그아웃 API가 인증 없이 요청 시 401을 반환한다
- [ ] 로그아웃 API가 Refresh Token이 이미 없는 상태에서도 성공(멱등)으로 처리한다

## 회원 탈퇴 (DELETE /api/v1/members/me)

- [x] 회원 탈퇴 후 동일 계정으로 로그인이 차단된다
- [x] 회원 탈퇴 API가 탈퇴 시 Refresh Token을 삭제한다
- [x] 회원 탈퇴 API가 탈퇴 후 동일 이메일로 재가입을 허용한다
- [x] 회원 탈퇴 API가 인증 없이 요청 시 401을 반환한다
- [ ] 회원 탈퇴 API가 탈퇴 후 재가입한 이메일로 로그인에 성공한다

## JWT 인증 필터

- [x] 인증 필터가 유효한 Access Token으로 인증 컨텍스트를 설정한다
- [x] 인증 필터가 만료된 Access Token으로 인증 컨텍스트를 비운다
- [x] 인증 필터가 서명이 잘못된 Access Token으로 인증 컨텍스트를 비운다
- [x] 인증 필터가 Refresh Token을 Access Token으로 사용하면 인증 컨텍스트를 비운다
- [x] 인증 필터가 Bearer 없는 Authorization 헤더를 무시하고 401을 반환한다
- [x] 인증 필터가 형식이 깨진 Bearer 토큰에 401을 반환한다
- [x] 인증 필터가 ADMIN 권한 없는 회원의 admin 엔드포인트 접근 시 403을 반환한다
